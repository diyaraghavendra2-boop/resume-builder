📊 Resume Builder - Data Flow Diagrams

Visual representation of data movement through the system

📝 CREATE RESUME FLOW
👤 User
→
📋 Form
→
✅ Validate
→
🌐 API
→
🔧 Backend
→
💾 MongoDB
→
✅ Success
1
User Input
User fills out resume form with personal information, skills, experience, and education
2
Frontend Data Collection
JavaScript collects form data into structured object
{ header: { name: "John Doe", email: "john@example.com" }, skills: ["JavaScript", "React", "Node.js"], experience: [{ title: "Developer", company: "Tech Corp" }] }
3
Frontend Validation
Client-side validation: required fields, email format, phone format
4
API Request
POST /api/resume with JWT token and JSON payload
POST /api/resume Headers: { Authorization: "Bearer JWT_TOKEN" } Body: { resume data in JSON format }
5
Backend Processing
Authentication, validation, data transformation, and business logic
6
Database Storage
MongoDB saves resume document with ObjectId, timestamps, and user association
{ _id: ObjectId("..."), userId: ObjectId("..."), header: { name: "John Doe" }, createdAt: ISODate("2024-01-28T..."), updatedAt: ISODate("2024-01-28T...") }
7
Success Response
Backend returns success response with created resume data
{ success: true, message: "Resume created successfully", data: { resume: { _id: "...", header: {...} } } }
8
UI Update
Frontend shows success message and updates interface
📖 FETCH RESUME FLOW
👤 User
→
🖱️ Click
→
🌐 GET API
→
🔐 Auth
→
🔍 Query DB
→
📦 Return Data
→
🎨 Render
1
User Request
User clicks "View Resume" or navigates to resume page
2
API Request
GET /api/resume with authentication token
GET /api/resume Headers: { Authorization: "Bearer JWT_TOKEN" }
3
Authentication
Backend validates JWT token and extracts user ID
4
Database Query
MongoDB query for user's resumes with sorting and pagination
Resume.find({ userId: req.user._id }) .sort({ updatedAt: -1 }) .limit(10)
5
Data Response
Backend formats and returns resume data with pagination info
{ success: true, data: { resumes: [{ _id: "...", header: {...}, skills: [...] }], pagination: { current: 1, pages: 1, total: 1 } } }
6
Frontend Rendering
JavaScript processes data and renders resume in UI
