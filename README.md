# Resume Builder

A modern, web-based resume builder with sharing and duplication functionality.

## Features

- **Interactive Resume Creation**: Fill out forms with live preview
- **Multiple Templates**: Minimal, Creative, and Corporate designs
- **Dark/Light Themes**: Toggle between themes with custom colors
- **Share & Duplicate**: Generate shareable URLs for others to copy and edit
- **PDF Export**: Download professional A4 format resumes
- **Mobile Responsive**: Works on all devices

## How to Use

1. Open `index.html` in your browser
2. Fill out your resume information
3. Choose a template and customize colors/fonts
4. Click "Share" → "Copy Shareable Link" to share with others
5. Friends can click "Use This Resume" to create their own editable copy

## Technologies Used

- HTML5, CSS3, JavaScript (ES6+)
- Font Awesome icons
- Google Fonts
- html2pdf.js for PDF generation
