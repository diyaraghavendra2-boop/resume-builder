🎯 MongoDB Compass - Find Resume Names

Step-by-step guide to see Purnima, manju, aarav, diya in resumes collection

🔄 Step 1: Switch to Resumes Collection

You're currently viewing the "users" collection. You need to switch to "resumes":

  • In the left sidebar, look for "resumes" (should be below "users")
  • Click on "resumes" collection
  • You should see 8 documents (not 4 like in users)
👀 Step 2: What Each Resume Document Looks Like

Each document in the resumes collection should have this structure:

{ "_id": ObjectId("679abc123..."), "userId": ObjectId("679def456..."), "title": "My Resume", "header": { "name": "Purnima", ← THE NAME YOU WANT! "role": "Software Developer", "email": "john.doe@email.com", "phone": "+1234567890", "location": "City, State", "linkedin": "linkedin.com/in/...", "website": "...", "profilePicture": "" }, "professionalSummary": "...", "skills": ["JavaScript", "React", "Node.js"], "experience": [...], "education": [...], "certifications": [...], "hobbies": [...], "isPublic": false, "createdAt": "2026-01-28T...", "updatedAt": "2026-01-28T..." }
🔍 Step 3: Find the Names

Look for these specific names in the "header.name" field:

✅ Expected Names:
• Document 1: "name": "Purnima"
• Document 2: "name": "manju"
• Document 3: "name": "aarav"
• Document 4: "name": "diya"
• Documents 5-8: "name": "Your Name" (defaults to ignore)
🛠️ Step 4: If You Don't See the Structure Above
Try these troubleshooting steps:

1. Expand Documents:
• Click the arrow (▶) next to each document to expand it
• Look for the "header" section

2. Change View Mode:
• Make sure you're in "Document" view (not "Table" view)
• Look for view toggle buttons at the top

3. Refresh Data:
• Click the refresh button (circular arrow)
• Wait a few seconds for data to load

4. Filter Out Defaults:
• Click "Filter" button
• Enter: {"header.name": {"$ne": "Your Name"}}
• This will show only the 4 named resumes
📋 Step 5: What You Should See

After switching to resumes collection, you should see something like:

Document 1: { "_id": ObjectId("..."), "header": { "name": "Purnima", "role": "Software Developer" } } Document 2: { "_id": ObjectId("..."), "header": { "name": "manju", "role": "Software Developer" } } Document 3: { "_id": ObjectId("..."), "header": { "name": "aarav", "role": "Software Developer" } } Document 4: { "_id": ObjectId("..."), "header": { "name": "diya", "role": "Software Developer" } }

🎯 Key Point:

You were looking in the "users" collection (which shows user accounts), but the resume names are stored in the "resumes" collection under "header.name"!
