🧭 MongoDB Compass Guide

Step-by-step guide to see your resume names

1
Open MongoDB Compass

Launch MongoDB Compass application on your computer

[Screenshot: MongoDB Compass startup screen]
2
Connect to Your Database

In the connection string field, enter:

mongodb://localhost:27017

Then click the "Connect" button

[Screenshot: Connection screen with localhost:27017]
3
Find Your Database

On the left sidebar, you should see a database called "resumebuilder"

Click on it to expand

⚠️ If you don't see "resumebuilder":
• Make sure your backend server is running
• Check if you see any other databases
• Try refreshing the connection
[Screenshot: Left sidebar showing "resumebuilder" database]
4
Open Resumes Collection

Under "resumebuilder" database, you should see collections:

  • users - Contains user accounts
  • resumes - Contains all resume data

Click on "resumes" collection

[Screenshot: Collections list showing "users" and "resumes"]
5
View Resume Documents

You should now see a list of documents. Each document represents one resume.

Look for these fields in each document:

{ "_id": "...", "userId": "...", "title": "My Resume", "header": { "name": "Purnima", ← THE NAME YOU WANT TO SEE "role": "Software Developer", "email": "john.doe@email.com", "phone": "...", "location": "..." }, "skills": [...], "experience": [...], "createdAt": "2026-01-28T...", "updatedAt": "2026-01-28T..." }
✅ What you should find:
• Documents with header.name = "Purnima"
• Documents with header.name = "manju"
• Documents with header.name = "aarav"
• Documents with header.name = "diya"
6
Filter Out Default Names (Optional)

If you see many documents with "Your Name", filter them out:

  1. Click the "Filter" button at the top
  2. Enter this filter:
{"header.name": {"$ne": "Your Name"}}

This will hide all documents where header.name equals "Your Name"

[Screenshot: Filter input with the filter applied]
7
Troubleshooting
If you don't see the names:

1. Check Document View:
• Make sure you're in "Document" view (not "Table" view)
• Look for the "header" object inside each document

2. Refresh the Data:
• Click the refresh button (circular arrow)
• Disconnect and reconnect to MongoDB

3. Check Document Count:
• You should see 8 documents total
• 4 with real names, 4 with "Your Name"

4. Expand Documents:
• Click the arrow next to each document to expand it
• Look inside the "header" object for the "name" field
8
Alternative: Use Web Viewer

If MongoDB Compass isn't showing the data clearly, use our web viewer:

http://localhost:8080/check-all-resume-names.html

This will show you exactly what's in your database in a user-friendly format.
